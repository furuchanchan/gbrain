# v0.57.0.27

`updateSlug` (sync rename, `gbrain sync` file moves) now keeps slug-keyed bindings attached to the page:

- `facts.entity_slug` / `facts.source_markdown_slug` move with the rename — facts no longer orphan under a deleted slug.
- `slug_aliases.canonical_slug` and `page_aliases.slug` follow the new name.
- A `slug_aliases` row for the old slug is recorded automatically, so `[[old-name]]` wikilinks and alias lookups keep resolving.
- The whole move is one transaction on both Postgres and PGLite; a destination collision still fails the rename before anything moves.
- No schema change or manual step required.
