# v0.56.1.1 — stripEmailHtml removes downlevel-revealed conditional blocks

`stripEmailHtml` removed ordinary `<!-- -->` comments but only ate the
markers of Outlook's downlevel-revealed conditional comments
(`<![if mso]>junk<![endif]>`), leaking the conditional body into stripped
text — including when the markers arrived entity-encoded.

The whole block (markers + contents) is now dropped in plain and encoded
forms. Blocks that never close are untouched: a bare `<![if x]>` opener
is discarded like other unrecognized `<![...]>` markup and the following
text stays visible.

No action required.
