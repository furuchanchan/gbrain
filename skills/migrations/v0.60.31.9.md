# Upgrade to v0.60.31.9: the nightly quality probe honors the brain's model config

Model routes the nightly quality probe takes now resolve against the
brain's own configuration:

- The LongMemEval reader resolves `models.eval.longmemeval` (then
  `models.tier.reasoning`, `models.default`, `GBRAIN_MODEL`) against the
  brain's config instead of ignoring it; the trajectory extractor does the
  same for `models.tier.utility`.
- The cross-modal judge slots accept `models.eval.cross_modal.slot_a`,
  `...slot_b` and `...slot_c` config pins, equivalent to `--slot-*-model`.
- When a judge slot's default provider is unavailable on the machine, the
  substitute model is the brain's resolved chat route (`models.chat` →
  `models.tier.reasoning`), not only the file-plane default.
- `gbrain models` lists the three slot keys and reports each slot's route
  the way the probe resolves it.

No data changes and nothing to re-embed. Only install-managed model
resolution changed.

1. **Optional: pin probe models.** To route the probe's reader or judge
   slots onto specific models:
   ```bash
   gbrain config set models.eval.longmemeval <provider>:<model>
   gbrain config set models.eval.cross_modal.slot_a <provider>:<model>
   ```
   Unset slots keep the documented defaults (and the chat-model
   substitute) exactly as before.
