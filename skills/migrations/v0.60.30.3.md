# v0.60.30.3 — get_timeline same-date tie-breaker (#5883)

`getTimeline` ordered by `date DESC` only, so entries sharing a date had no
defined order and a `limit` could keep an arbitrary one of them.

The read now breaks ties on `te.id DESC` (newest insertion first), matching
the chronicle reads in the same module. Both engines pick this up through
the shared `engine-sql` implementation.
