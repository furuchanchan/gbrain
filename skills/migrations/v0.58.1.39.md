# v0.58.1.39 — widening g_history_days now backfills the newly covered slice

Raising `g_history_days` on a google source after its gmail backfill
completed used to silently import nothing — the backfill gate was closed
forever and the delta lane only moves forward. The state file now records
the window edge the completed backfill covered; when a sync sees the
configured window reach past it, the backfill reopens seeded at that edge
and drains only the newly covered older slice.

No action needed — the next `gbrain sync --source <id>` picks up the new
mail automatically. State files written before this version seed the edge
from the current window on their first run.
