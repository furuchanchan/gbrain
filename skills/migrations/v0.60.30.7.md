# v0.60.30.7 — think gather opts out of adaptive return sizing (#5890)

With `search.adaptive_return` enabled, `sizeReturnPool` trims first-page
result sets to the intent cap — 2 pages for `entity` intent, 6 for every
other intent — before the limit slice. The reader-facing cap is right for
`search`/`query` answers, but `runGather`'s hybrid legs size for breadth
(`gatherLimit` 40) so synthesis can cite what the brain actually holds.

Both legs now pass `adaptiveReturn: false` beside the existing
`expansion: false` and `autocut: false` (#4561) pins, for the same reason:
an internal evidence gather is not a reader-facing answer page. The op
`search`'s `adaptive_return` override and the global
`search.adaptive_return` config are unchanged for user-facing calls.
