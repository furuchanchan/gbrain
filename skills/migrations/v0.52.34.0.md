# v0.52.34.0: chronicle backfill cursor + idempotent extraction

No upgrade action is required. Existing chronicle event pages, timeline
projections, and job history are preserved; the coverage cursor derives from
the existing job ledger, so previously completed extractions are recognized
without a reset. A page that gained an extraction-versioned event will not be
re-extracted for unchanged content — edit the page if you want a fresh pass.
