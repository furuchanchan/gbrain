# v0.54.47.0 — Per-root push-status attribution

`bootstrap status`'s `support.last_push` and doctor's `bootstrap_push_health` now scope to the current workspace root's own push receipt instead of an aggregate pick across all roots.

- `status`: `last_push` reads the receipt keyed to `realpath(ws)`; `null` when this root has none (another root's receipt no longer stands in).
- `doctor`: the git probe pairs only with this root's receipt age. Other roots' staleness remains an aggregate warn; a root with no receipt warns instead of borrowing another root's "ok". Single-legacy-receipt attribution is unchanged.

No state migration needed — existing receipts are read as-is.
