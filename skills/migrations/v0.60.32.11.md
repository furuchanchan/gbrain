# Upgrade to v0.60.32.11: publication failure records carry the cause

No migration steps — this release changes one error message.

- A managed publication that failed with a non-`OperationError` used to
  record only `Publication failed. Inspect owner diagnostics.` The durable
  `error_message` now carries the cause: the original message plus the
  constructor name when the error has no `.code`, secret/DSN/URL-redacted
  and bounded to 240 characters (#5929).
- Existing failure records are unchanged; new records get the fuller text.
- The issue's remaining asks — a doctor/status surface for the last
  publication error and stale-owner-process detection after
  `gbrain self-upgrade` — are not in this release.

No paid work, no permissions, no schema changes. `gbrain upgrade` applies it.
