- `gbrain sources reconcile` no longer refuses a body or frontmatter edit just because the file's copy of a private fact row carries stale field values (#6137). A private row at its stored row number with its stored claim and visibility is now taken from the stored row, so the file edit publishes while every stored private row stays byte-identical; a file that renumbers a private fact or changes its visibility still refuses with `permission_denied`.
