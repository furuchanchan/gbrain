- `gbrain schema add-type` no longer requires `--prefix`: omitting it writes `path_prefixes: []`, matching what the manifest format and pack linter already allow (#6135). A one-line note explains the type is set by frontmatter only and never inferred from a path. An explicitly empty prefix and `--expert` without a prefix still fail, since the pack linter rejects expert routing that can never match a path.
