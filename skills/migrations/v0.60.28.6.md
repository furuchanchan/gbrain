# v0.60.28.6 — Migration Notes

No schema migration is required.

New config key (#5854): `persistence.maintenance_publish_wait_ms` — the
milliseconds the managed maintenance publish path waits for the writer
before returning `write_pending`. Default 5000 (unchanged behavior). On
hosts where the writer lane regularly runs a few seconds behind (e.g.
Postgres through a transaction pooler), raise it:

```
gbrain config set persistence.maintenance_publish_wait_ms 15000
```
