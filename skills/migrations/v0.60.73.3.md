title: v0.60.73.3
---

- `gbrain sources set-path` and writer-transfer manifests now hash only the files git sees inside a work tree (tracked plus untracked-non-ignored — the same set sync ingests) instead of every file on disk: dependency trees, build output, and gitignored credentials like `.env.local` are no longer read or hashed, and rebinding to a new directory no longer requires copying them byte-for-byte (#6099). Non-git directories keep the raw filesystem walk. Rebinding still verifies an exact match over that set, and symlinks still refuse the canonical manifest.
