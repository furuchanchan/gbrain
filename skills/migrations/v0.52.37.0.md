# v0.52.37.0: classified + bounded embed-effect deadline

No upgrade action is required. If a local embedder routinely needs more
than 25s per page, set `GBRAIN_EFFECT_EMBED_TIMEOUT_MS` (milliseconds) on
the serve process — e.g. `900000` for 15 minutes. Effects that exhausted
their attempts under older versions stay `failed`; clear them via doctor
or requeue by editing `persistence_effects.state` if you want them retried
under the new bound.
