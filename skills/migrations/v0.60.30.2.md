# v0.60.30.2 — find_orphans paging + per-row source provenance (#5891)

`find_orphans` (MCP op) previously returned every orphan row in a single
response with no bound and no way to tell which source a row belonged to.

Now:
- `limit` (default 200, max 1000) and `offset` page the returned rows;
  `total_orphans` still reports the full filtered count so callers can page.
- `source_id` narrows the read to one granted source — denied ids throw
  `permission_denied`, removed/archived ids throw `unknown_source`.
- Each orphan row carries `source_id` and `type`.

CLI `gbrain orphans` and doctor are unchanged (they call the shared data
function without a limit, keeping the legacy unbounded shape).
