# Upgrade to v0.54.30.0: honest managed-brain messaging for markdown reindex

Preserve existing identity, grants, source routing, capture choices and provider
settings. This release changes only messaging and early refusal behavior; it
does not require activating a new writer topology and makes no schema change.

## Memory-only upgrade

```bash
GBRAIN_NO_AUTOPILOT_INSTALL=1 GBRAIN_NO_REEMBED=1 gbrain upgrade --no-autopilot-install
```

The autopilot option propagates through package hooks and migration orchestration
and skips service-unit rewrites. `GBRAIN_NO_REEMBED=1` separately skips potentially
paid reindexing; other migrations still run. For a source clone linked with Bun,
follow the [installation upgrade steps](../../INSTALL_FOR_AGENTS.md#upgrade).

## What changes for managed brains

- `gbrain reindex --markdown` now refuses the whole sweep up front with one
  clear `writer_coordinator_required` message, instead of attempting every
  selected page and printing one identical refusal per page.
- `gbrain doctor`'s `contextual_retrieval_coverage` check no longer prescribes
  `gbrain reindex --markdown` on a managed brain — it names the managed writer
  coordinator as the path for re-evaluation.
- A managed-safe markdown reindex path is still pending. Pages behind on
  chunker or contextual-retrieval evaluation are unchanged; on unmanaged brains
  the sweep and the doctor hint behave exactly as before.

## If rollback is necessary

Reverting the binary restores the previous per-page refusal behavior and the
previous doctor hint. No migration, ownership change, or queued repair depends
on this release; nothing needs to be drained or reverted first.
