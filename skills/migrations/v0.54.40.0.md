# Upgrade to v0.54.40.0: session-end hook skips gbrain's own claude-cli transcripts

Preserve the agent's identity, capture choices, provider choices and source
grants. This release removes a self-ingestion feedback loop; it does not
change what user sessions are captured or how consent works.

## Upgrade the installation

1. For a managed brain, identify and gracefully stop/drain its owner and older
   workers on every host using the deployment's normal shutdown procedure.
   Keep a verified full database backup and the original installation. A Git
   remote alone is not a full backup.
2. Upgrade through the installation's supported path:

   ```bash
   gbrain upgrade --no-autopilot-install
   ```

3. Restart the upgraded owners/workers and verify `gbrain --version` and
   `gbrain sources writer status --json`.

## If self-captures already accumulated

The upgrade stops NEW captures; it does not remove existing ones. Corpus files
written by gbrain's own calls can be recognized by their `User: <turn>`-style
extraction-prompt content inside `~/.gbrain/transcripts/corpus/` (or the
configured `dream.synthesize.session_corpus_dir`). Removing them by hand is
safe — they are intermediate capture files, not pages — and keeps the dream
synthesize phase from treating them as sessions again. Pages already
synthesized from those captures can be withdrawn individually; they are
ordinary pages in the database.
