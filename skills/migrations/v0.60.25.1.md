# Migrating to v0.60.25.1

No schema changes and no config moves are required.

## What changed for you

- **`gbrain embed --stale` is honest about skipped pages.** If a page's projection snapshot becomes unavailable while the sweep runs, the run now counts those chunks as failed and exits non-zero with the remedy ("inspect the page and source before retrying") instead of reporting `Embedded 0 chunks` success. Pages skipped this way keep their stale chunks and embed normally on the next run once the projection is sealed again.
