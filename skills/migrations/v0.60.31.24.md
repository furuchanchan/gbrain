# Migration notes — v0.60.31.24

## Slug-collision loser files can now be deleted through sync (#5565)

No action required. If an incremental `gbrain sync --source <id> --no-pull` failed with `A different origin occupies the imported slug` after removing one of two files that shared a slug, re-run the same command — the deletion is now admitted and the surviving page is untouched. Sources left with a `sync_incomplete` receipt recover on the next successful run; `gbrain sync --source <id> --no-pull --full` confirms convergence.
