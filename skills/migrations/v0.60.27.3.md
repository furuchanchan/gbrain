# v0.60.27.x — Auto-drain owner gate

Autopilot's extract-atoms auto-drain now skips sources that have no canonical
atom owner on this host instead of submitting jobs that retry and dead-letter.
Managed brains with connector sources (Google/GitHub) or worktrees owned by
another host will simply see fewer dead `extract-atoms-drain` jobs; nothing to
do — the source's owning host drains it.
