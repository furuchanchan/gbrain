# v0.60.115.0

## dream triage: unreliable verdicts cached as 24h markers (#6069)

Degenerate judge verdicts (unparseable / truncated / refused) were previously
discarded unlogged and re-paid every cycle. They are now written to
`dream_verdicts` as marker rows (`score` null, `reasons[0]` =
`unreliable:<kind>`) that suppress the paid re-judge for 24 hours per
(file_path, content_hash), then age out so the transcript is re-judged. The
stderr log line includes the first 1500 chars of the raw judge response. No
action needed; a persistently failing judge now costs at most one call per
hash per day instead of one per cycle.
