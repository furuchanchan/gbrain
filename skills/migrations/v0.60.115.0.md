title: v0.60.115.0
---

- `sources reconcile` no longer refuses a page whose canonical file shares its basename with more than 100 other pages in the source (for example date-named chat-archive files like `channels/<name>/2015-09.md`): the candidate-origin check now pages through every basename-sharing page instead of throwing `Too many candidate page origins`, so drifted pages with common filenames can be reconciled again. Genuine conflicts (two pages recording the same resolved file) still refuse.
