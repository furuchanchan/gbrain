# v0.60.10.17 — hardening follow-up for `sources set-path --clear`

No action required. This release tightens `gbrain sources set-path <id> --clear`'s
safety check: when the connector-binding table cannot be read for any reason
other than the table simply not existing (non-persistence installs), the command
now fails loud instead of treating the source as unbound and clearing it.
