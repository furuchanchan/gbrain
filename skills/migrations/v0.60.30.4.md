# v0.60.30.4 — --json stdout clean of the AI SDK warning banner (#5892)

`gbrain query --json` / `gbrain dream --json` emitted a non-JSON first
line — "AI SDK Warning System: ..." — whenever a claude-cli
(LanguageModelV2) model ran, because the SDK's `logWarnings` prints the
banner with `console.info` before writing warnings to stderr.

The CLI entrypoint now installs `globalThis.AI_SDK_LOG_WARNINGS` as a
function that forwards the same warnings to stderr. An operator-set value
(`false` or a custom logger) is never overridden. The stdio serve path
was already safe (`redirectStdoutLoggingToStderr`).
