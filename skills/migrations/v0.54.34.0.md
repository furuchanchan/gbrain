# v0.54.34.0

## test(persistence): pin the remote put_page revision contract (#5271)

Test-only change — no runtime behavior change.

`test/put-page-remote-revision.test.ts` drives `put_page` through a
remote (untrusted) `OperationContext` — the same shape MCP dispatch
produces — and pins:

- the advertised tool schema exposes `expected_revision`, `force`,
  `request_id`, `source_id` (shared `PAGE_MUTATION_PARAMS`);
- remote create → read revision → replace with `expected_revision`
  commits;
- a stale `expected_revision` rejects with `revision_conflict`;
- `force: true` overwrites without a revision;
- a replace with no precondition is refused (create-only, by design).

No schema change. No operator action required.
