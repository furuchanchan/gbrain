# Upgrade to v0.60.52.2: the enrich skill files entities by the active schema pack

`skills/enrich/SKILL.md` previously routed every new entity through hardcoded
`people/` / `companies/` templates, so a brain whose active pack declares
finer entity types (e.g. `investment_firm` → `investment-firms/`) got
misfiled pages, `type: company` where the pack expected another type, and
`null` placeholder contact fields.

No action is needed. If pages were already filed under the wrong directory
or type, they stay as they are — re-file them manually or leave them; the
skill now resolves each entity's type, directory and subtype from the active
pack (`skills/brain-taxonomist/SKILL.md`, or `gbrain schema show --json`)
before writing, omits frontmatter keys whose values are unknown, and writes
link-target pages before the pages that reference them.
