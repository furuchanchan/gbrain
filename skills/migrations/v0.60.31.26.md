# Migration notes — v0.60.31.26

## `bootstrap harness --help` is safe again (#5488)

No action required. `gbrain bootstrap harness --help` (and `-h` / `help`) now prints the subcommand's usage and exits 0 instead of running the real harness apply — minting a bearer token and writing MCP/hook config — that an operator only meant to inspect. If a past `--help` run unexpectedly wired a harness on a machine, `gbrain bootstrap harness --status` shows what exists and `gbrain bootstrap harness --remove --yes` tears it down.
