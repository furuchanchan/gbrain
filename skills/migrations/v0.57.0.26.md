# v0.57.0.26

Transcript re-ingest now tracks sessions by identity instead of display slug.

- A session whose title or start date changed (re-rendered under a new slug) is UPDATED at its existing page instead of dedup-skipped — appended messages and re-redaction now land.
- Frontmatter keys the collector does not render (e.g. `reviewed` flags set by other tools) are preserved across re-ingests.
- Stale `*-pN` parts are enumerated by `transcript_import.session_id`, so parts stranded under a previous base slug are still removed.
- Re-run `gbrain transcripts ingest` to re-render already-imported sessions; no migration or data change is required.
