# Upgrade to v0.60.10.6: grounding recognizes stock `[role]` transcript boundaries

Synthesis verification now understands the standalone `[user]` /
`[assistant]` boundary lines emitted by the stock Claude Code transcript
renderer. Previously those transcripts parsed with no turn structure at
all, so a `Name:` label inside an earlier assistant turn could be recorded
as the speaker of a later user quote with no mismatch reported. Speaker
attribution and speaker-mismatch quarantine now apply to stock-format
transcripts. No schema migrations and no new configuration.

1. **Confirm the upgrade finished on the brain host.**

   ```bash
   gbrain --version          # expect 0.60.10.6 or newer
   ```

   If `gbrain doctor` reports a partial migration, run
   `gbrain apply-migrations --yes --no-autopilot-install` on the brain host.

2. **Nothing else to do.**

   Verification applies the boundaries automatically on the next synthesis
   pass. Pages already written keep their recorded `grounding.quotes[].speaker`;
   correct a known-bad page with a revision-bound `put_page` — no repair
   command exists for historical attribution.
