# v0.60.10.13

- Checkpoint harvest, the maintenance sweep's corpus pass, and the checkpoint compact banked-turn path now gate extraction on the model GBrain will actually run — including a DB-plane `facts.extraction_model` override (#5735). Installations that configured a local model via `gbrain config set facts.extraction_model` (e.g. `ollama:*`) while leaving file/env providers unset were misclassified as `keyless` and corpus files stayed unprocessed; on upgrade the next sweep/harvest pass processes the backlog normally. Callers that inject an explicit capability report (tests, the serve pipeline) keep their override semantics. No operator action required.
