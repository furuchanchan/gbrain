# v0.60.28.1 — Migration Notes

No schema or config migration is required.

Behavior change (#5823): `extract-conversation-facts`, the
`conversation_facts_backfill` cycle phase, and `transcripts ingest --facts`
no longer apply the *defaulted* cost cap when the resolved extraction model
has no pricing entry (e.g. a `claude-cli` subscription recipe). The run
proceeds uncapped with a stderr notice instead of aborting at $0 with
`budget_exhausted` / `no_pricing`.

Explicitly configured caps (`--max-cost-usd`,
`cycle.conversation_facts_backfill.max_cost_usd` / `max_total_cost_usd`,
`transcripts ingest --facts --max-cost-usd`) are unchanged: they stay
enforced and fail fast with a `no_pricing` message that names the model and
the `pricing.overrides` remediation.

To restore a cap on an unpriced model, declare a rate:

```bash
gbrain config set pricing.overrides '{"<provider>:<model-id>": <usd-per-1M-tokens>}'
```
