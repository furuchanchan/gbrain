# v0.52.3.0: conversation-extraction skip-cause visibility

No upgrade action is required. Existing extraction checkpoints, durable
outcomes, and skip markers are preserved unchanged.

After upgrading, run `gbrain extract-conversation-facts --dry-run` once to see
the per-cause skip breakdown. Pages previously reported only as skipped may
now surface a specific cause (for example, unparseable speaker turns); those
pages are retried on the next extraction run without any state reset. Do not
delete checkpoints or re-scan markers to force re-extraction — the existing
causes already distinguish work that should be retried from work that is done.
