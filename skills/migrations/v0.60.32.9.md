No migration steps — this release widens one repair settlement path.

- If `gbrain repair embedding-effects --apply` reported
  `blocked_no_replacement_obligation` on pages whose current revision is
  fully embedded, re-run it after upgrading — those effects now commit
  `superseded` (`verified: current_vectors_complete` in the outcome).
- Effects whose current revision still has missing or stale vectors, or
  whose projection cannot be read, keep the
  `no_replacement_obligation` refusal.
- No manual database UPDATE was or is required; the settled effect no
  longer blocks receipt compaction.

No paid work, no permissions, no schema changes. `gbrain upgrade` applies it.
