# Migration: v0.60.28.0

Fixes `get_links`, `get_backlinks`, and `traverse_graph` for callers without an operator source grant on brains with multiple federated sources (#5827). These ops previously pinned to the scalar routing source — usually `default`, which holds no pages — so the link graph appeared empty while `search` and `get_page` (which already widen to the federated set) worked normally. No schema or data changes; unqualified link reads now see the same source set as unqualified searches.
