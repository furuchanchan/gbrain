# v0.60.116.0

## managed sync: group admission adopts a member's single-path row (#6075)

A managed sync cursor that formed a bulk group while a non-bulk caller
admitted the group's head on the single-page path wedged forever: the head's
committed row lacks the `group` marker, so `assertReplayIntent` rejected the
re-admission with `idempotency_conflict` and the run stopped at the same
index every cycle. Group admission now accepts a member's existing row when
its intent matches minus the keys group formation adds (`group`, `after`,
`lane`) — the single-path row is adopted into the group — and still conflicts
on a genuinely different intent. No action needed; a wedged source resumes on
the next pass.

## publication failures: codeless errors keep their name and message (#6075)

A publication failure from an error with no code previously recorded only
`storage_error` / "Publication failed. Inspect owner diagnostics." — the
original exception went nowhere. `error_detail` on the request row now
carries `cause: { name, message }` (owner-only, message bounded at 400
chars), so the next `gbrain sources writer status --probe` shows what
actually failed instead of a generic refusal. No action needed.
