# Migration notes — v0.60.31.21

## Managed sync stamps sources.chunker_version on --full runs (#5566)

No action required. A managed brain whose quiet sources report `sync_freshness` WARN/FAIL despite healthy syncs will clear the flag after the next `gbrain sync --source <id> --full` completes — the checkpoint now records the chunker version it verified, matching the legacy path. Incremental syncs intentionally do not write the stamp: they never visited the unchanged files, so claiming the current chunker for the whole corpus would hide pages still carrying an older version.
