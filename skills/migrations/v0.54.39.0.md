# Upgrade to v0.54.39.0: metafile pages no longer wedge effect scans

Preserve the agent's identity, capture choices, provider choices and source
grants. This release corrects a background-worker stall; it does not change
what is written, who may write it, or how ownership transfers work.

## Upgrade the installation

1. For a managed brain, identify and gracefully stop/drain its owner and older
   workers on every host using the deployment's normal shutdown procedure.
   Keep a verified full database backup and the original installation. A Git
   remote alone is not a full backup.
2. Upgrade through the installation's supported path:

   ```bash
   gbrain upgrade --no-autopilot-install
   ```

3. Restart the upgraded owners/workers and verify `gbrain --version` and
   `gbrain sources writer status --json`.

## If withdrawal-mirror effects were stuck

Brains whose `withdrawal-mirror` effects retried a single slug with
`error_code='source_changed'` (visible in `persistence_effects`) resume
automatically: the next worker tick skips the metafile-classified page and the
cursor advances. The sibling `git` and `embedding` effects that were queued
with zero attempts drain normally afterward. Nothing needs to be deleted or
reclaimed; do not remove ownership markers or rewrite the effects table by
hand.
