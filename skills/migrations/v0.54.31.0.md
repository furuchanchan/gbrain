# v0.54.31.0

- Writer topology administration (`writer claim`, `writer activate`, `writer transfer prepare|accept`) now hard-refuses non-interactive callers (#5285): an agent or cron job can no longer replay `--admin-intent`/`--expected-state` to change ownership. Run these at a terminal. Reviewed provisioning automation may set `GBRAIN_ALLOW_UNATTENDED_WRITER_ADMIN=1` — the intent and reviewed-state gates still apply, and dry runs remain scriptable.
