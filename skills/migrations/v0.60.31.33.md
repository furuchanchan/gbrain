# Migration notes — v0.60.31.33

- **Prefix-bound clients can now remember and forget (#5913).** A client whose `oauth_clients.bound_slug_prefixes` is set previously got `permission_denied` at the dispatch gate for `remember`, `forget` and `forget_fact` — even though each op resolves a concrete slug and fences on it. The ops are now admitted and the resolved slug is fenced, so writes land only under the client's prefixes. One behavior note: `remember` without an `entity` targets `memory/unattributed`, which sits outside every prefix — bound clients must name an in-prefix entity (or the call denies `permission_denied`, fail-closed). Unbound clients and local CLI are unchanged.
