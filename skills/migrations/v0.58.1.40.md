# v0.58.1.40 — edge resolution now reaches search and CLI output

`gbrain edges-backfill` used to write `resolved_chunk_id` into edge
metadata that nothing read. Now:

- `gbrain query --walk-depth` / `--near-symbol` follows the resolver's
  pick (or its ambiguous candidates) instead of re-matching the symbol
  name across every file that defines it.
- `code-callers` / `code-callees` show `[in-file: resolved]` /
  `[in-file: ambiguous]` for resolved same-file edges (`[resolved]`
  still means the edge lives in the chunk table).
- `--json` edge output gains `resolution` and `resolved_chunk_id`
  fields; the `resolved` flag is unchanged.

No migration needed — metadata written by earlier backfills is read as-is.
