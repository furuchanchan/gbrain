# v0.57.0.30

Doctor/onboard checks report `warn` "not verified" when they could not run, instead of `ok`:

- `schema_pack_consistency`, `schema_pack_source_drift`: query errors warn; the success text notes pack membership is not checked.
- `multi_source_drift`: missing/unreadable `local_path` (root or any subdirectory) and truncated walks surface as incomplete coverage; `GBRAIN_DRIFT_LIMIT` and `GBRAIN_DRIFT_TIMEOUT_MS` now actually tune the walk on both the local and the remote (thin-client) doctor.
- `embed_staleness` counts through `engine.countStaleChunks()` — the same predicate the embed worker uses.
- `reranker_health`, `atom_provenance_drift`, `subagent_capability` messages now state exactly what was measured (historical audit rows, bounded quote probe, dispatch-refusal vs fallback).

No action required.
