# v0.57.0.41 — incremental calendar sync respects the window

Previously, once a calendar source held a syncToken, any change to a
recurring series imported every expanded instance — bursts of ~700
phantom pages spanning years. The sweep now applies the same
[history, future] window to incremental results, and the forward edge is
configurable per source: `g_future_days` (default 60), settable as
`--future-days` on `gbrain sources add`.

If a source already accumulated phantom instances, run
`gbrain sync --source <id> --full` once — the new window reconcile
soft-deletes live calendar pages outside the window (the >200 mass-delete
guard applies, same as the gmail reconcile).
