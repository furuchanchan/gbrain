# Upgrade to 0.60.31.10: gbrain's report pages store a declared type

Pages gbrain writes itself now use page types the default `gbrain-base-v2`
pack declares:

- The drift phase's `reports/drift-<date>` page and `gbrain report` pages
  are stamped `type: note` (the pack's catch-all) instead of the
  undeclared `report`; the report kind stays on `report_type`.
- The reports skill's frontmatter template matches (`type: note` +
  `report_type`).
- Meeting-ingestion now names `type: meeting` for the raw-transcript
  sidecar page.

Nothing to re-embed and no action is required. Pages already stored with
`type: report` or an undeclared transcript type keep their type; the
pack's catch-all retype rule (`unify-types`) can normalize them, and
`gbrain schema lint --with-db` lists what remains.
