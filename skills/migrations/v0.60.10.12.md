# v0.60.10.12

- `migrate-embeddings --apply --max-cost-usd` now settles each request's debit to measured usage instead of holding the `maxInputTokens` ceiling for the whole run (#5680). A `--max-cost-usd` near the plan's printed `Estimated cost` now covers the run; attempts that produced no usage record keep their ceiling debit (conservative accounting is preserved). The exhaustion refusal now reports the operator's actual `--max-cost-usd` and cumulative debit rather than the confusing `--max-cost $0.00` / `cumulative $0.0000` from the per-call tracker. No operator action required; brains that hit the cap on earlier versions resume by re-running `migrate-embeddings --apply`.
