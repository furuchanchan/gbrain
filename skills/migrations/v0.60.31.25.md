# Migration notes — v0.60.31.25

## `embed <slug>` repairs signature- and hash-stale pages (#5527)

No action required. `gbrain embed <slug>` and `gbrain embed --slugs` now re-embed a page whose `embedding_signature` predates the current model — and, with `--include-null-signature`, a page that was never stamped — instead of reporting "already embedded" and leaving the previous vector space in place. The same runs re-embed any chunk whose stored text hash no longer matches its content. If the sync-time "previous model's embedding space" warning persists for a page you can name, `gbrain embed <slug> --include-null-signature` is now a working per-page repair; `gbrain embed --stale --include-null-signature` remains the corpus-wide one.
