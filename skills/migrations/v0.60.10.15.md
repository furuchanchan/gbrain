# v0.60.10.15

- `gbrain config set embedding_query_prefix` now works as documented (#5691). The key was readable on all three config planes but absent from `KNOWN_CONFIG_KEYS`, so the documented `config set` command was rejected as unknown. If you previously worked around this with `--force` or by editing `config.json`, no action is needed — the stored value is honored either way. When setting a Qwen3-style instruction, use ANSI-C quoting so the newline is stored for real: `gbrain config set embedding_query_prefix $'Instruct: ...\nQuery:'` (a plain single-quoted `\n` stores a literal backslash-n).
