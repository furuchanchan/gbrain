# Upgrade to v0.58.1.24: durability hook correctly excluded under core.hooksPath=.githooks

Preserve the agent's identity, capture choices, provider choices and source
grants. This release changes only how `sources harden` classifies the active
hooks directory; it does not change stored data or access policy.

## Upgrade the installation

1. For a managed brain, identify and gracefully stop/drain its owner and
   older workers on every host using the deployment's normal shutdown
   procedure. Keep a verified full database backup and the original
   installation. A Git remote alone is not a full backup.
2. Upgrade through the installation's supported path:

   ```bash
   gbrain upgrade --no-autopilot-install
   ```

3. Restart the upgraded owners/workers and verify `gbrain --version` and
   `gbrain sources writer status --json`.

## Repairing a previously hardened repo

On a repo that was hardened while `core.hooksPath` pointed inside the
working tree, re-running `gbrain sources harden` adds the missing
`.git/info/exclude` entry. If the hook was already committed by an earlier
`sources push`, remove it from the index (`git rm --cached <hookdir>/post-commit`)
once — the exclude entry keeps it untracked afterwards.
