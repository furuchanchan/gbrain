# Migration notes — v0.60.31.28

## extract-conversation-facts --json emits a machine-readable summary

`gbrain extract-conversation-facts --json` now prints a single JSON object carrying the same counters as the human `Done:` summary — `dry_run`, `outcome` (`segmentation_only` or `extracted`), `sources`, the full `pages_*`/`segments_processed`/`facts_*` counters, `spent_usd`, and `budget_exhausted` — instead of rejecting the flag with `Unknown flag`. The prose summary is suppressed under `--json`; exit codes (0 clean, 1 page failures, 3 lock-skipped) and stderr progress lines are unchanged.
