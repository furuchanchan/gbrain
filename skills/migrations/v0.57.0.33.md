# v0.57.0.33 — extract-conversation-facts honors `--json`

The generated CLI flag registry advertised `--json` for
`extract-conversation-facts`, but the command's own parser refused it
with `Unknown flag: --json` (exit 1). Wrappers that only read stdout saw
a silent no-op.

`--json` is now accepted: after the run, the summary is emitted as a
single JSON object carrying the same counters as the text `Done:` report
— `dry_run`, `sources`, `spent_usd`, `budget_exhausted`, and every
aggregate page/fact counter. Exit-code semantics (0/1/3) are unchanged.

No action required.
