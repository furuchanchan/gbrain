# v0.54.32.0

## fix(reindex): bound pages per PGLite connection (#5284)

`runReindex` re-opens the engine at batch boundaries once the
processed-page count crosses `GBRAIN_REINDEX_PGLITE_REOPEN_EVERY`
(default 500), bounding the page writes pushed through one long-lived
PGLite connection — the measured trigger for the commit wedge in #5284.

- Env: `GBRAIN_REINDEX_PGLITE_REOPEN_EVERY` (default `500`; `0` disables).
- File-backed PGLite: `engine.reconnect()` re-opens the data dir (fresh
  WASM runtime). In-memory engines: documented no-op, state preserved.
- No schema change. No operator action required.
