# Upgrade to v0.60.10.10: `get_page` can include the structured timeline store

`get_page` returned the `pages.timeline` column verbatim — the markdown
`<!-- timeline -->` sentinel section — while entries appended by
`add_timeline_entry` / auto_timeline live only in the `timeline_entries`
table. Pages with structured entries therefore reported `timeline: ""`,
and clients needed a second `get_timeline` call. `get_page` now accepts
`include_timeline: true`, adding a `timeline_entries` field (same shape
as `get_timeline`) scoped to the resolved page's own source.

1. **Confirm the upgrade finished on the brain host.**

   ```bash
   gbrain --version          # expect 0.60.10.10 or newer
   ```

2. **Use it where you previously chained `get_page` + `get_timeline`.**

   ```bash
   gbrain get notes/example --include-timeline        # CLI
   # or MCP: get_page { "slug": "notes/example", "include_timeline": true }
   ```

   Existing behavior is unchanged: without the flag, `timeline` stays the
   markdown sentinel section exactly as before, and `get_timeline` keeps
   its date-window and limit filters for callers that need them.
