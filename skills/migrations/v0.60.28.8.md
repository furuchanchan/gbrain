# Migrating to v0.60.28.8

## What changed

Remote reads of `visibility: private` facts can now be widened by an
operator opt-in (#5857). Nothing changes by default — remote/MCP callers
still see world-only facts until the key is set.

## If you rely on it

Single-user brains where every connected agent is equally trusted can
expose legacy private facts to remote readers:

```bash
gbrain config set search.remote_private_facts visible
```

Widening applies to facts only (`recall`, `context_pack` / `delta`
`include_private`, entity cards, `find_trajectory`, `think`, page/evidence
`## Facts` fences). Private *pages* remain under the separate
`search.remote_private_pages` key, and `include_private` is still required
per call on `context_pack` / `delta`. Clearing the key (`''`) restores
enforcement within ~30s. `GBRAIN_REMOTE_PRIVATE_FACTS=1` is the process
escape hatch.
