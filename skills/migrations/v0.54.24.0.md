# v0.54.24.0: `embed --stale` seals the projection gap

No operator action is required for normal upgrades: stale embedding runs now
queue and drain pending projection rebuilds themselves (unmanaged brains) or
defer to the writer coordinator (managed brains). Pages that previously sat
permanently between a canonical write and a projection seal — invisible to
the stale reader yet counted by the stale counter — are embedded by the next
`gbrain embed --stale` pass.

1. If `embed --stale` previously reported a large dry-run count but embedded
   nothing, re-run it once after upgrading; the same pass now seals pending
   projections and embeds their chunks.
2. On managed brains the coordinator seals queued rebuilds on its poll
   cycle; the embed run now prints a warning naming that path instead of
   silently reporting zero progress.
3. `EmbedResult` gains `skipped_unsealed`, `skipped_mismatch`,
   `skipped_unreadable`, and `install_conflicts` counters; the CLI prints a
   summary warning when any are non-zero.
