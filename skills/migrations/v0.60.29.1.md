# v0.60.29.1

## Atom pages no longer queue facts extraction (#5831)

`extract_atoms` output pages (`atoms/*`, type `atom`) no longer feed the
facts backstop — they are derived digests of pages whose facts were
already extracted, so each atom was spending a `facts-absorb` LLM call on
derived text and producing entity-less facts that `consolidate` could
never drain.

- `gbrain recall --pending` now counts only facts the consolidator can
  reach (rows with an `entity_slug`); entity-less facts remain stored and
  readable, they just no longer inflate the backlog number.
- Existing entity-less fact rows are untouched. Atom pages already
  published stay published — they simply stop queueing new facts-absorb
  jobs.
